# 歌手照片目录

把歌手照片放在这里，歌手详情页的大头像就会用它。

## 使用方式

1. 在 GitHub 网页打开 `Resources/Artists/`
2. 点 **Add file → Upload files**
3. 上传照片，**文件名必须等于歌手名**，例如：
   - `周杰伦.jpg`
   - `Jay Chou.jpg`（如果标签里存的是英文名）
4. 提交后等 CI 构建完成，重新签名安装

## 支持的格式

`.jpg` / `.jpeg` / `.png` / `.heic`

## 没放照片会怎样

会自动使用该歌手**最早一张专辑的封面**作为头像
（对周杰伦来说就是《Jay》那张，本身就是人像照），
再没有才回退到「首字 + 渐变圆」。

## 建议

- **正方形**图片效果最好（会按圆形裁切）
- 尺寸 600×600 以上即可
- ⚠️ 仓库是公开的，请勿上传有版权的商业宣传照
