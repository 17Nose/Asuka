# 内置音乐目录

把 `.m4a` / `.mp3` / `.flac` 等音频文件直接放在这个文件夹里，
GitHub Actions 构建时会自动打包进 App，安装后打开就能看到。

## 使用方式

1. 在 GitHub 网页上打开 `Resources/Music/` 目录
2. 点 **Add file → Upload files**
3. 把音频文件拖进去，提交
4. 等 CI 构建完成，下载新的 IPA 重新签名安装

## 支持子文件夹

可以建子文件夹分类，扫描器是递归的，例如：

```
Resources/Music/
├── 周杰伦/
│   ├── 晴天.m4a
│   └── 稻香.m4a
└── 纯音乐/
    └── river-flows-in-you.m4a
```

## 注意事项

- ⚠️ **仓库是公开的**，请勿上传有版权的商业音乐（DMCA 下架风险）
- 📦 音频很占体积，建议控制总量在 200MB 以内，否则构建会明显变慢
- 🔄 每次新增文件都需要**重新构建 + 重新签名安装**才能生效
- 💡 如果只是想临时加几首歌，用 App 内的「导入」按钮更方便，不用重新构建

## 歌词

同名 `.lrc` 文件放在音频文件旁边即可自动识别，
也可以在播放器里点「歌词 → 在线搜索」自动下载。

_此说明文件不会影响 App 运行，可以删除。_
